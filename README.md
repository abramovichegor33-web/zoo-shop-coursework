# 🐾 Магазин зоотоваров

В проекте реализованы две полноценные версии информационной системы на C# (.NET 8), работающие с единой базой данных MySQL:
1. **Десктопное приложение** — `src/ZooShop` (C#, Avalonia UI 11)
2. **Веб-приложение (полный веб-аналог)** — `src/ZooShop.Web` (C#, ASP.NET Core Razor Pages)

## Структура репозитория
- `src/ZooShop` — исходный код десктопного приложения
- `src/ZooShop.Web` — исходный код веб-приложения
- `database/create_tables.sql` — SQL-скрипт создания и заполнения базы данных (`zoo_shop`)
- `docs` — ER-диаграмма и пояснительная записка

## Тестовые аккаунты
- **Администратор:** логин `admin`, пароль `admin123` (доступно добавление и удаление товаров)
- **Покупатель:** логин `user`, пароль `user123`

---

## Инструкция по запуску

### 1. Подготовка базы данных (MySQL)
Убедитесь, что сервер MySQL запущен на `localhost:3306` (пользователь `root`, пароль `root1234`, база `zoo_shop`).
Если база ещё не создана, выполните скрипт:
```bash
mysql -u root -proot1234 < database/create_tables.sql
```

### 2. Как запустить десктопное приложение (Avalonia)
Откройте Терминал и выполните команду:
```bash
dotnet run --project ~/Documents/GitHub/zoo-shop-coursework/src/ZooShop
```
На экране откроется окно программы «Магазин зоотоваров».

### 3. Как запустить веб-версию (ASP.NET Core Razor Pages)
Откройте Терминал и выполните команду:
```bash
dotnet run --project ~/Documents/GitHub/zoo-shop-coursework/src/ZooShop.Web
```
После появления строки `Now listening on: http://localhost:5123` откройте в браузере адрес:
👉 **http://localhost:5123**

*(Остановить работающий сервер в Терминале можно нажатием клавиш `Ctrl + C`).*

### 4. Как запустить обе версии одновременно (для демонстрации)
1. В первой вкладке Терминала запустите веб-сайт (`dotnet run --project ~/Documents/GitHub/zoo-shop-coursework/src/ZooShop.Web`) и откройте `http://localhost:5123`.
2. Нажмите `Cmd + T` в Терминале (откроется вторая вкладка) и запустите десктопное приложение (`dotnet run --project ~/Documents/GitHub/zoo-shop-coursework/src/ZooShop`).
Оба приложения подключены к одной БД `zoo_shop`: любые заказы или новые товары, добавленные в одной версии, сразу отображаются во второй.
